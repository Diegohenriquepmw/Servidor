# Pasta de Imagens dos Produtos

Esta pasta deve conter as imagens dos seus produtos.

## Como adicionar imagens:

1. Faça upload das suas imagens para esta pasta (`images/produtos/`)
2. No painel admin do site, ao adicionar uma imagem, você pode usar apenas o nome do arquivo (ex: `meu-produto.jpg`)
3. O sistema automaticamente ajustará o caminho para `images/produtos/meu-produto.jpg`

## Formatos recomendados:
- JPG para fotografias
- PNG para imagens com transparência
- WebP para melhor compressão (navegadores modernos)

## Tamanhos recomendados:
- Largura máxima: 800px
- Qualidade: 80-90% para JPG
- Sempre otimize as imagens antes do upload
